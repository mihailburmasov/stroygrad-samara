## Две ветки — это главное

| Ветка | Что в ней | Где работает |
|---|---|---|
| `main` | Сайт на **Node-сборщике** (`build/*.mjs`), без админки | Живой сайт: https://mihailburmasov.github.io/stroygrad-samara/ (GitHub Pages, пуш в `main` = деплой) |
| `php-admin` | Сборщик переписан на **PHP** (`app/lib`) + админка (`app/admin`) + приём заявок (`app/lead.php`) + заливка по FTP (`app/bin/deploy.php`) | **https://стройград-самара.рф** — Beget, с 25.09.2026. Запушена в GitHub. |

- **Не сливать `php-admin` в `main` до переезда**: формы там шлют заявки на `/lead.php`, которого на GitHub Pages нет.
- **Каждую правку сайта сейчас делать в обеих ветках.** Так делалось всю сессию: сначала `main` (сборка, `check.mjs`, коммит, пуш, ждём деплой), потом то же в `php-admin`. Картинки переносятся через `git checkout main -- <файлы>`. JSON в `php-admin` другого формата (отступ 2, LF), поэтому данные туда вносятся через PHP (`json_pretty`), а не копированием файла из `main`.
- В день переезда: `deploy.php init`, проверка на хостинге, потом слить `php-admin` в `main` и выключить GitHub Pages. Иначе останется вторая, устаревшая копия сайта.

## Как работать локально (ветка `php-admin`)

```
php app/bin/build.php                                   # собрать dist/
php -S 127.0.0.1:8080 app/dev-router.php                # сайт + админка /admin/ + заявки
```
- PHP 8.3 установлен через winget: `%LOCALAPPDATA%\Microsoft\WinGet\Packages\PHP.PHP.8.3_*\php.exe`. В `php.ini` включены gd, mbstring, ftp, curl, exif, zip, intl. В PATH он попадает только после перезапуска терминала.
- `app/config.local.php` — локальные настройки, в git не хранятся (адрес 127.0.0.1:8080, без секретного адреса входа). Вход в локальную админку — пароль `test-pass-123` (хранится в `storage/`, в git не попадает, на сервер не уезжает).
- Тесты (round-trip всех разделов, API, headless Chrome, эмуляция заливки) лежат в навыке: `~/.claude/skills/php-json-admin/tests/`.

## Грабли этой сессии

- **Коллажи hero**: `npm run art` перезаписывает `data/hero.json` только переводами строк — перед коммитом `git checkout -- data/hero.json`. Добавление фото в `main` делается скриптом в папке проекта (`import sharp from 'sharp'`), а не из временной папки: там не находится `node_modules`.
- **PowerShell**: `.Replace()` с `$`, кавычками и `${...}` в коде часто молча не срабатывает — проверять результат или править через Edit. Ещё: `Remove-Item env:SITE_BASE` инструмент блокирует как «удаление корня», надо писать `$env:SITE_BASE=$null`.
- **Git Bash**: `/tmp` = `%LOCALAPPDATA%\Temp`, там лежит scratchpad сессии. Не использовать `git stash` для «проверки на чистоту»: он прячет незакоммиченную работу.
- **При смене ветки** в `main` появляются неотслеживаемые `app/` и `storage/` — это локальные файлы ветки `php-admin`. В коммиты `main` их не брать, добавлять файлы поимённо.
- **Чужие файлы**: `stroygrad-client-questions.docx` — личный документ, в git не добавлять.
